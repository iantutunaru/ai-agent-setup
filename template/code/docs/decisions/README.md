# Decisions

The user's decisions, one log per area (e.g. `design.md`, `process.md`), newest at the bottom of each, ids never
reused: `<P>-Qnn` project-wide, `<P>-Txx-Qn` for a ticket's own (those may also sit in the ticket file's decision
table). A settled decision stands unless the user reopens it.
