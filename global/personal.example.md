# About the user

The lines about one person, loaded in every project beside the shared rules (`global/rules.md` says which file
wins). This file lives in `local/`, which git ignores: it stays on this machine and is copied to another PC by
hand. The install made it from `global/personal.example.md`; while a line below says "not set", nothing is set
there and the shared default applies.

## Preferences

They win over the shared rules on these points only, and a project's own file wins over them. Replace "not set"
with your own words, or delete the line to keep the shared default.

- **Language:** not set. (Which language the assistant talks to you in.)
- **Background:** not set. (What you know, so that analogies in plain-language explanations fit.)
- **Model:** not set. (The shared default is in `global/rules-claude.md` and `global/rules-chatgpt.md`.)
- **Chat size:** not set. (The same files give the shared default.)
